# C-TAC Generator Pro

Interactive Compiler Education Platform — a browser-based C to Three-Address Code compiler for learning compiler design.

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd insight-builder-v4.0-main

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Scripts

| Command          | Description                          |
| ---------------- | ------------------------------------ |
| `npm run dev`    | Start development server             |
| `npm run build`  | Build for production                  |
| `npm run lint`   | Run ESLint                            |
| `npm run preview`| Preview production build              |
| `npm run test`   | Run tests                             |
